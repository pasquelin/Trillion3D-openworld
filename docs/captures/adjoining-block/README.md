# Adjoining street block preview

These are real engine screenshots of the revised one-block workload: adjoining apartment rows, varied heights and materials, service passages, and two supplemental CC0 buildings in the courtyard. The scene contains 16 buildings and 144,507 instance-expanded authored triangles.

The public engine pin is `7f810cbe344ee10fdcc910a8f5659e1536edbc2d`. The assembled source SHA-256 is `e74caad3b90c3de5950ddbd2936a52ea592d70f9dd2797c07574ddef76ba9b6c`. The JSON evidence records the captured report and artifact hashes; source changes continued during the preview, so it does not represent final island acceptance.

Chromium 151 rendered this preview using WebGL2 and the SwiftShader software driver at 1280 × 720. The scene reached ready with no captured uncaught JavaScript exceptions. The alley and skyline images were visually inspected. This is visual and loading evidence, not a hardware performance or physics benchmark.
